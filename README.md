# IBM Data Analyst Module Assignment

This repository contains the assignment for the **IBM Data Analyst course**, focusing on essential data analysis techniques and tools.

## **Project Overview**
The goal of this assignment was to:
- Extract financial data using the **yfinance API**
- Fetch and parse web data using the **Beautiful Soup** library
- Process and analyze extracted data

Through this project, key data analysis skills were applied to gather, manipulate, and present meaningful insights using Python.

## **Technologies Used**
- **Python** - Core programming language for data processing
- **yfinance** - API for retrieving financial market data
- **Beautiful Soup** - Library for web scraping and parsing HTML content
- **Pandas & NumPy** - Data manipulation and analysis
